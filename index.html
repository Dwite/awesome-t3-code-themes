  1. Put the theme file in the themes folder of T3 Code. Run one command:
    macOS and Linux
    Windows (PowerShell)
    Or download the file and move it to ~/.t3/userdata/themes/ yourself.
  2. T3 Code finds the file by itself. Choose the theme in T3 Code, or ask the agent in T3 Code to switch to it.
To go back, choose a built-in theme.
