Koi Pond Studio

Settings for the Koi Pond theme for T3 Code. The preview is the real theme.

How to install the theme

Save to T3 Code asks once for the themes folder: ~/.t3/userdata/themes. In the folder dialog, press Cmd+Shift+G and paste that path. After that, every change is written to koi-pond.json and T3 Code shows it at once. Choose the theme "Koi Pond" in T3 Code the first time.

Download theme gives you koi-pond.json. Put it in the themes folder, or send it to a friend. The file keeps its settings: Open theme file loads them back.

A theme has no script. So koi cannot follow clicks, be fed, or know the time. The pond follows light and dark mode; the command node cli.js sync sets the time of day from the clock.
